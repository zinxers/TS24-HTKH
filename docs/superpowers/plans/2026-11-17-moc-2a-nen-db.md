# Mốc 2a: nền DB — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PostgreSQL (Supabase) chạy được ở máy và CI, có bảng `team`, `app_user` với luật đặt ở DB, role `ts24_app` quyền tối thiểu, và `packages/db` (postgres.js) có repository, type sinh từ DB, `check:rls`, test trên DB thật.

**Architecture:** Schema, role, RLS nằm trong một migration Supabase. `packages/db` bọc postgres.js: `createSql` → `Database.transaction` → `BaseRepository` → `TeamRepository`, `UserRepository`. Test DB (`*.db.test.ts`) tách khỏi `turbo test`, chạy bằng `test:db` khi có DB; CI dựng DB trong job `check`.

**Tech Stack:** Supabase CLI 3.1 (`pnpm supabase`), Docker, PostgreSQL, postgres.js, TypeScript strict, Vitest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-17-moc-2a-nen-db-design.md`

## Global Constraints

- `db` chỉ phụ thuộc `@ts24-htkh/shared` và thư viện ngoài; điểm vào `src/index.ts` giữ `import 'server-only'`. Không nới `.dependency-cruiser.cjs`.
- Mọi câu SQL có giá trị từ ngoài dùng tagged template của postgres.js (không ghép chuỗi; tên bảng trong `BaseRepository` qua `sql(table)`).
- Tên bảng/cột đúng spec: `team(id, name, sort_order, created_at, updated_at)`, `app_user(id, email, full_name, role, team_id, status, password_hash, failed_login_count, created_at, updated_at, deleted_at, deleted_by)`; `role` ∈ `head|manager|staff`; `status` ∈ `active|locked`.
- 3 team, đúng thứ tự: `Thuế, Kế toán và Hệ thống quản lý` (1), `Bảo hiểm xã hội và Quản lý nhân sự` (2), `Hóa đơn điện tử, Hải quan và Chuyển đổi số` (3).
- Role `ts24_app`: `nologin` trong migration; `login` + mật khẩu dev `ts24_app_dev` chỉ trong `supabase/seed.sql` (giá trị dev công khai, không dùng ở staging/production).
- URL mặc định khi không có env: `postgresql://ts24_app:ts24_app_dev@127.0.0.1:54322/postgres` (`DATABASE_URL`) và `postgresql://postgres:postgres@127.0.0.1:54322/postgres` (`DATABASE_ADMIN_URL`, chỉ cho test quyền và `check:rls`).
- Test DB không có DB thì fail, không skip. `turbo test` không đòi Docker.
- Không tạo project Supabase cloud, không gọi Supabase MCP để ghi.
- Commit Conventional Commits, scope `db` (hoặc `ci`, `docs`). Lệnh turbo kèm `--no-daemon`, `TURBO_TELEMETRY_DISABLED=1`.

### Task 2: `Database`, repository, type sinh từ DB

**Files:**
- Create: `packages/db/src/types.generated.ts` (sinh), `packages/db/src/database.ts`, `packages/db/src/repositories/base.repository.ts`, `packages/db/src/repositories/team.repository.ts`, `packages/db/src/repositories/user.repository.ts`, `packages/db/src/repositories/repositories.db.test.ts`
- Modify: `packages/db/package.json` (script `gen:types`), `packages/db/src/index.ts`, `packages/db/eslint.config.js` (bỏ qua `types.generated.ts` nếu lint báo)

**Interfaces:**
- Consumes: Task 1 (`Sql`, `createSql`, `appSql`, `inRollback`).
- Produces:
  - Script `gen:types`: `supabase gen types typescript --local > src/types.generated.ts`.
  - `type TeamRow = Database['public']['Tables']['team']['Row']`, `type UserRow = …['app_user']['Row']` (từ `types.generated.ts`).
  - `class Database { constructor(sql: Sql); transaction<T>(fn: (tx: Sql) => Promise<T>): Promise<T> }`
  - `abstract class BaseRepository<Row> { constructor(sql: Sql, table: string); findById(id: string): Promise<Row | null>; softDelete(id: string, actorId: string): Promise<void> }` — đọc lọc `deleted_at is null`; `softDelete` đặt `deleted_at = now()`, `deleted_by = actorId`, chỉ dòng chưa xóa.
  - `class TeamRepository { constructor(sql: Sql); list(): Promise<TeamRow[]> }` (theo `sort_order`; team không xóa nên không kế thừa `BaseRepository`).
  - `class UserRepository extends BaseRepository<UserRow> { findByEmail(email: string): Promise<UserRow | null> }` — chuẩn hóa `trim().toLowerCase()` trước khi tìm.
  - `index.ts` xuất: `createSql`, `Sql`, `Database`, `BaseRepository`, `TeamRepository`, `UserRepository`, `TeamRow`, `UserRow`, `PACKAGE_NAME`.

- [ ] **Step 1: `pnpm --filter @ts24-htkh/db gen:types`, kiểm file có `app_user`, `team`.**

- [ ] **Step 2: Viết `repositories.db.test.ts` (fail trước)**, mỗi `it` trong `inRollback(appSql(), …)`, repository tạo với `tx`:
  - `TeamRepository.list()` → 3 dòng, `name` đúng thứ tự Global Constraints.
  - `UserRepository.findByEmail(' A@Example.com ')` tìm thấy dòng `a@example.com` vừa chèn; `findByEmail('khong-co@example.com')` → `null`.
  - `findById` của dòng đã `softDelete` → `null`; `findByEmail` của dòng đó → `null`.
  - `softDelete(id, actorId)` → đọc lại bằng SQL thô thấy `deleted_at` không null, `deleted_by = actorId`.
  - `softDelete` dòng `head` → reject (trigger DB).
  - `new Database(tx).transaction(...)` ném lỗi bên trong → dòng chèn trong đó không còn (kiểm sau bằng `select`).
