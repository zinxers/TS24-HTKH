# Mốc 0: khung monorepo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monorepo pnpm + Turborepo chạy được, chưa nghiệp vụ: lint/typecheck/test/depcruise đạt, web có trang chào, CI chạy trên PR.

**Architecture:** Workspace `apps/*`, `packages/*`, `tools/*`. Cấu hình dùng chung ở `@ts24-htkh/config`; `tsconfig.base.json` ở gốc kế thừa nó cho depcruise. Package rỗng khai báo phụ thuộc đúng `docs/architecture.md` mục 2.

**Tech Stack:** Node 26, pnpm 12.18.0, Turborepo, TypeScript strict, Next.js App Router, Vitest, ESLint flat config, Prettier, dependency-cruiser, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-17-moc-0-design.md`

## Global Constraints

- `"packageManager": "pnpm@12.18.0"`, `"engines": { "node": ">=26" }`; không dùng corepack.
- Tên package `@ts24-htkh/<tên>`; phụ thuộc nội bộ `"workspace:*"`; `"private": true`.
- TypeScript `strict: true`; xuống dòng LF.
- Mỗi package (trừ `config`, `desktop`) có scripts `lint`, `typecheck`, `test`.
- Không nới luật trong `.dependency-cruiser.cjs`. Không dùng `--passWithNoTests`.
- Thư viện ngoài: bản stable mới nhất lúc cài; `pnpm add <pkg> --filter <package>`, công cụ chung `pnpm add -Dw <pkg>`.
- Commit Conventional Commits trên nhánh `chore/moc-0-khung-monorepo`; **dừng sau mỗi task** để người dùng kiểm tra.

## Review Focus

1. Package khai báo thừa/thiếu phụ thuộc so với sơ đồ → test gốc ở Task 3 so `package.json` với bảng mong đợi.
2. Giao diện web lỡ import `@ts24-htkh/core` → Task 6 tạo file vi phạm tạm, depcruise phải báo lỗi.
3. Thiếu `server-only` ở `core`/`db`/`storage` → test Task 3 kiểm dependency và dòng import ở `src/index.ts`.
4. CI cài lệch lockfile → Task 7 chạy `--frozen-lockfile` ở local trước khi push.
5. Turbo cache sai do thiếu `outputs` → Task 4 build web hai lần, lần 2 phải `FULL TURBO`.
