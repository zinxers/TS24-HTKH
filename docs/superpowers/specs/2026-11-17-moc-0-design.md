# Mốc 0: khung monorepo (design)

- Ngày: 2026-11-17 · Trạng thái: chờ duyệt
- Nguồn: `CLAUDE.md`, `docs/architecture.md`, ADR-0001.

## Mục đích

Dựng khung monorepo chạy được, chưa có nghiệp vụ, để từ Mốc 1 mọi code đã có chỗ đặt đúng lớp và luật kiểm tra (lint, typecheck, test, depcruise, CI).

## Mục tiêu

- `pnpm install` → `pnpm turbo lint typecheck test` đạt, `pnpm depcruise` sạch.
- `pnpm turbo dev --filter=@ts24-htkh/web` mở http://localhost:3000 thấy trang chào.
- CI chạy lint/typecheck/test/depcruise trên mỗi PR.

## Không làm (để mốc sau)

- Nghiệp vụ, Supabase, migration, RLS, `check:rls`, xác thực.
- Tauri chạy được, Rust, job CI Windows.
- Phần còn lại của `ci.yml` theo `.claude/rules/ci-cd.md` (supabase, build web, gitleaks); `deploy.yml`, `release-desktop.yml`, `backup.yml`.
- Remote cache Turborepo.

## Chống mục tiêu

- Nới luật depcruise để code chạy được.
- Package khai báo phụ thuộc ngoài sơ đồ mục 2 của `docs/architecture.md`.
- Test rỗng pass chỉ nhờ `--passWithNoTests`.

## Ràng buộc

- Node `26.13.1`, pnpm `12.18.0` (máy người dùng); không có corepack.
- `main` có ruleset `protect-main`: chỉ vào qua PR.
- TypeScript `strict`, LF, tên package `@ts24-htkh/<tên>`, phụ thuộc nội bộ `workspace:*`.

## Phương án

| Phương án | Đánh đổi | Chọn |
|---|---|---|
| 1. Một nhánh, một PR, mỗi bước một commit, dừng sau mỗi bước | Ít thao tác, `main` không nửa vời; CI chỉ có từ bước cuối | **Có** (người dùng chọn) |
| 2. Mỗi bước một PR | Review từng bước trên GitHub; ~7 PR, các PR đầu chưa có CI | Không |

Phạm vi desktop/tools: người dùng chọn **B**, khung rỗng (không Tauri chạy được, không Rust).

## Thiết kế

Nhánh `chore/moc-0-khung-monorepo`. Mỗi bước một commit Conventional Commits, dừng cho người dùng kiểm tra.

1. **Root:** `package.json` (`private`, `packageManager: pnpm@12.18.0`, `engines.node >=26`, scripts `lint typecheck test dev build depcruise`), `pnpm-workspace.yaml` (`apps/*`, `packages/*`, `tools/*`), `turbo.json` (`build`, `typecheck`, `test` phụ thuộc `^build`; outputs `.next/**`, `dist/**`), `tsconfig.base.json` kế thừa `@ts24-htkh/config` (depcruise đọc file này).
2. **`packages/config`:** tsconfig dùng chung (base, library, nextjs), ESLint flat config, Prettier. Không có test.
3. **Package rỗng:** `shared`, `platform`, `db`, `storage`, `xlsx-report`, `core`. Mỗi package: `src/index.ts`, 1 smoke test Vitest, scripts `lint typecheck test`. Dependencies đúng sơ đồ: `core → db, storage, xlsx-report, shared`; `db, storage, xlsx-report → shared`; `shared`, `platform` không phụ thuộc nội bộ. `core`, `db`, `storage` có `server-only`.
4. **`apps/web`:** Next.js App Router, trang chào ở `src/app/(pages)/page.tsx`, `src/app/api/v1/` để trống, phụ thuộc `shared`, `platform`, `core` (cho API). `transpilePackages` cho package nội bộ.
5. **Khung rỗng:** `apps/desktop/package.json` (`@ts24-htkh/desktop`, không phụ thuộc nội bộ); `tools/sheets-migration/README.md`, `tools/backup-verify/README.md`.
6. **depcruise:** thêm `dependency-cruiser` ở root, script `depcruise`, chạy sạch. Không sửa luật.
7. **CI:** `.github/workflows/ci.yml` (`pull_request`, push `main`): `pnpm/action-setup` → `setup-node` 26 (cache pnpm) → `pnpm install --frozen-lockfile` → `pnpm turbo lint typecheck test` → `pnpm depcruise`. Commit kèm `.github/rulesets/protect-main.json`. Push, mở PR.

## Để người làm tự quyết

- Bản Next.js, TypeScript, ESLint, Vitest: bản stable mới nhất lúc cài, lockfile ghim.
- Nội dung trang chào: tên hệ thống + dòng "Mốc 0", không style cầu kỳ.
- Lệnh kiểm tra người dùng tự chạy sau mỗi bước: ghi trong plan.
